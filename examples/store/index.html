Сторы

Стор cart объявлен один раз в cart.js. Каталог, корзина и бейдж в шапке — независимые компоненты, которые его читают.

Код

Три способа достать стор

const cart = useCart()              // функция, которую вернул defineStore
defineComponent('x', (ctx, { cart }) => ...) // второй аргумент setup
Plainly.store('cart')               // по имени, откуда угодно
