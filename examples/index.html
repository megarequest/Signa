Plainly — примеры

Каждый пример — отдельная папка: index.html + JS без сборки. Открываются прямо из файла.

  • Основыsignal, computed, пропсы из data-*, слоты, сигналы в дочерние компоненты
  • СторыdefineStore, три способа доступа, данные из PHP
  • Todocomposable, состояние фильтра в URL через Plainly.location
  • Роутерhash-маршруты, параметры, именованные ссылки
  • Dropdownобёртка <ui-dropdown> вокруг любой кнопки и любого содержимого
  • Selectвыпадающий список <ui-select>: поиск, клавиатура, формы, зависимые списки
  • Модальные окна<ui-modal> на <dialog>, confirm / prompt через Promise, тосты
